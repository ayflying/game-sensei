## 二、眠枭系统全解（本批最大收获）

上一批 200P 只留下「眠枭之星」词频，本批还原完整链路：

```
点亮眠枭石像 ──→ 获得眠枭之星（分颜色：黄色…）
                    │
采得/种得「某精灵的果实」
（护主犬的果实 / 棋棋的果实 / 鸭吉吉的果实 …每种精灵专属）
                    │
                    ▼
        放入「眠枭庇护所」
        （果实花纹决定会吸引哪种精灵）
                    │
                    ▼
   消耗对应颜色眠枭之星「滋养」庇护所
   （如：滋养一座需 3 枚黄色眠枭之星）
                    │
                    ▼
   吸引该精灵前来「栖息」
   ⇒ 「精灵的模样似乎会发生变化」
   （庇护所限定外观的个体 → 图鉴收集/外观收集点）
```

- 证据：`TreeFruitAll_P009`「放入眠枭庇护所后能吸引某种精灵过来栖息」「其花纹可以知道什么精灵会被吸引」；`LuokeStar228_P035_f0060`「滋养这座庇护所需要 3 枚黄色的眠枭之星，你当前拥有 0 枚」；`FengmianStar147_P001`「点亮眠枭石像获得」。
- **自动化含义**：眠枭石像点位是可脚本化的世界交互（点亮→拿星）；庇护所滋养是「果实→限定个体」的定向获取线。
- 规模：风眠省 147 颗 + 洛克里安 228 颗 = **至少 375 颗眠枭之星**。

## 三、首领战通用打法（星星魔法 + 投掷）

世界首领（含隐藏宝箱守卫）的通用机制，OCR 原文实证：

- 「请使用**星星魔法**击破首领的护盾」（`HiddenBoxAll_P002_f0008` / `P008_f0009`）
- 「击破首领护盾，请**投掷精灵获得增益**」（`HiddenBoxAll_P008_f0007`）
- 「首领挑战技巧：击中精灵首领的**头部**能造成**暴击**，更有效击破护盾」（`LuokeStar228_P025_f0002`）

⇒ **投掷玩法有部位判定：瞄准头部 = 暴击 = 快速破盾**。这是上次素材「精灵投掷万能互动」的关键量化补充——自动化投掷的准星应锁定首领头部高度。

## 四、守护地副本结构

「守护地一条龙」视频（236 帧，本批最大样本）还原的副本骨架：

- **门槛是钥匙物收集**：「开启副本需要这 5 个水晶球」（`GuardLand100_P027_f0002`）、「开启副本需要找 5 个相框木桶」（`P028_f0004`）⇒ 不同守护地要不同钥匙物。
- 副本内含「**收集屋**」（12 次）——屋内再收集：6 个水晶球合成、三只「记忆石」挑战。
- **游戏币小游戏**：「1号：5个游戏币 / 2号：9个 / 3号：7个 / 4号：11个」（`P030_f0022`）、「上升过程一共32个游戏币」（`P025_f0006`）⇒ 屋内有计件小游戏，产出游戏币与水晶球。
- 副本奖励线：水晶球合成 →「冒出了十瓶绿油油的小药剂」（`P027_f0019`）。
- 场景解谜元素高频词：木桶(28)、火炬(20)。

## 五、华丽宝箱与隐藏收集

- **NPC 对话触发宝箱**：「我们对话完之后就出现一个华丽宝箱」「出来一个华丽宝箱」（`ThrowSpiritAll_P003/P009/P020`）⇒ 华丽宝箱多为对话/投掷交互触发，不在地图上直接显示。
- 隐藏收集分类（HiddenBoxAll）：**初级/中级/高级** 三级宝箱 + **隐藏称号** + **隐藏任务**。
- 「闻香识洛克」「拾遗任务」= 支线收集任务名。
- ⚠️ **地图宝箱不会刷新**（233乐园攻略页原文）——收集类自动化是一次性收益，做完即止。

## 七、方法学备忘

- **UP 主水印会污染词频**：本批「酥糖蛋/酥糖毛毛蛋/酥糖美美蛋」全部是 UP 主水印字幕（后缀 bilibili 水印被 OCR 混入），一度误判为游戏道具。**判读时凡词频高但无交互界面佐证的名词，先查是否为水印/弹幕。**
- 「不知明名/不知XX」高词频 = 地图上的未探索点标注（「未知名字」），本身是信号：说明地图有迷雾机制。
