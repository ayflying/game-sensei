## 二、精灵踪迹系统 = 眠枭庇护所（解决疑问 ②）

**关键纠正**：地图上的「精灵踪迹：N/M」**不是独立系统**，它是**眠枭庇护所**（地图建筑）的收集进度条。

### 2.1 完整链路

```
地图点开眠枭庇护所建筑
  → 弹窗：「在庇护所中放入果实，会吸引新的精灵来此处栖息」
  → 右侧显示「精灵踪迹」列表
  → 每条踪迹 = 家族名 + 形态描述 + 出现时段 + 属性
  → 点「传送」直接飞到该区域
```

### 2.2 界面原文转录（游戏内实拍）

界面元素完整形态（以大型庇护所为例）：

```
大型眠枭庇护所
在庇护所中放入果实，会吸引新的精灵来此处栖息。
精灵踪迹
  小狮鹫家族
    高山地的样子        全天
    小狮鹫    翼
    学院驻地
    神圣狮鹫  翼
    皇家狮鹫  翼
精灵踪迹：10/14          ← 右下角计数
[传送]                    ← 底部按钮
```

### 2.3 踪迹条目的四个字段

| 字段 | 含义 | 实例 |
|---|---|---|
| **家族名** | 该踪迹对应的精灵家族 | 小星光家族 / 小狮鹫家族 / 地鼠家族 / 蹦蹦种子家族 |
| **形态描述** | 当前栖息形态 | 月光能量的样子 / 高山地的样子 / 储水时的样子 / 短毛球形态 |
| **出现时段** | **关键**：全天 / 白天 / 夜晚 | 小星光=全天；地鼠=夜晚；蹦蹦种子=白天 |
| **属性** | 家族各进化形态属性 | 光·电 / 翼 / 地 / 毒·草 |

### 2.4 实操要点（零氪抓奇遇精灵的正解）

1. **先塞果实、再看踪迹、认准时段、最后传送** —— 顺序不能颠倒
2. **时段是硬门槛**：白天去蹲夜晚宠（如地鼠）等于白跑。界面写了"夜晚出没"就等夜里再来
3. **庇护所是最省资源的筛子**：它替你缩小了"区域 + 时段"两个维度，剩下那步才叫抓
4. 果实来源：图鉴解锁后地图果实树产出；**抓同一只精灵 20 次**也能获得该精灵果实
5. 没有的果实可去**好友世界**的庇护所白嫖

### 2.5 与既有记录的衔接

- 第二批文档记录的「点亮石像得星 → 专属果实放入庇护所 → 耗对应颜色星滋养 → 吸引模样变化个体」，**就是本系统的内在机制**；本批补齐了它的**地图入口与界面形态**
- 实测看到的「精灵踪迹：9/12」「12/14」「69/120」（后者是区域总进度）均可解释

## 三、月陨星在大世界怎么找（解决疑问 ②）

**关键纠正**：月陨星**不是"探索地图随机遇到"**，而是**连续捕捉触发的奇遇事件**。

### 3.1 触发方式

```
在大世界连续用咕噜球捕捉精灵
  → 累积到一定次数 → 触发赛季奇遇「星陨流光」
  → 天际坠下流星（星辰坠落事件）
  → 流星落地后浮在月壤上，可交互
```

- **必须是"连续捕捉"**，不是随机遇怪。站桩跑图永远不会出
- 走到流星附近时，**周围天光会被染成夜晚**——这是最可靠的识别特征（屏幕色调突变）
- 两种事件：**月陨星**（常规，掉 1 颗流星）/ **月陨流星雨**（极低概率，砸下 10 颗流星化作精灵）

### 3.2 四种月陨星（官方口径）

| 类型 | 产出 | 处理建议 |
|---|---|---|
| **白月陨星** | 混血精灵 / **异色精灵** | 目标，必抓 |
| **紫月陨星** | 污染血脉 / 奇异血脉精灵（**不出异色**） | 想省球可直接跳过 |
| **赤月陨星** | 赤月阵营精灵（幽铃、未完虫等） | 按需 |
| **金月陨星** | 金月阵营精灵（芽眼魔、布灵等） | 按需 |

- 紫/白由**外观颜色**直接区分；赤/金是**白月经战斗能量转化**后的两主题形态
- 转化规则：攻击类技能积**赤星**能量，状态/防御/聚能类积**金星**能量，较多一方决定形态
- **保底 80 次**；切换月陨星**不会重置**保底计数

### 3.3 月陨流星雨（对应往期"狂欢时刻"）

- 一次性落地约 10 只精灵，可捕捉或战斗
- **全部计入保底次数**（比 S2 狂欢时刻强）
- 触发期间地图上有**可追踪标记**，精灵抓完后标记消失
- 不一定出异色；持续时间有限

### 3.4 高效刷取地点

- **精灵密度高的低等级区域**（如普拉塔草原）：抓低级野怪速度快 → 连续捕捉效率高 → 触发奇遇更快
- 不要在低密度区硬刷

## 四、本批新增知识点

### 4.1 S4 异色清单（共 17 只）

- **奇遇异色 8 只**（赛季限定，赛季结束无法通过奇遇获得）：未完虫、智慧章脑、布灵、小浣蛋、星星眼、测风蝉、玳龟、超能球球
- **其他异色 9 只**：小黑猫、刺轮砣（分上弦/下弦）、觅觅蝠、逗逗、小灵菇、芽眼魔、瑰眼仔、叮叮卯
- **帕尔异色**：S4 同步上线

**注意**：S4 起**不能看性格和特长了**，拿到手才能细看；小黑猫也**不是纯白色**——不要靠外观猜。

### 4.2 月涌棱镜球（S4 赛季炫彩球）

- 银白色为主、镶点金芒，伪黑白炫彩效果
- **孵化稀有精灵蛋时选用**：特殊效果一并生效，出炫彩外观 + "了不起天分"的概率更高

### 4.3 四大学院（新系统）

| 学院 | 加成 | 适合 |
|---|---|---|
| 精灵学院 | 学院小窝；精灵生蛋**稳定继承性格** | 孵蛋党 |
| 炼金学院 | 合成咕噜球**概率多产出** | 刷异色玩家 |
| 仪典学院 | 商店**额外刷新机会** | 时装爱好者 |
| 战斗学院 | 合成战斗道具**消耗减半** | PVP 玩家 |

### 4.4 精灵视野（通用技巧，非 S4 专属但此前未录）

- **手机端**：召唤非坐骑跟随宠 → 点左侧「抱起/牵手」→ 点右下角眼睛图标
- **PC 端**：`Shift+R` 快速开关
- 效果：地面显示**彩色脚印**、高亮**隐藏宝箱/线索**
- 前提：必须是非骑乘、可跟随的精灵（坐骑/飞行宠不行）
- 太远不显示，需靠近目标

### 4.5 银月狼王补充（与第三批互证）

- 主线第一章领**诅咒狼灵蛋**；满月领地试炼刷**月陨碎片 / 月之牙**
- 进化链：诅咒狼灵(28级) → 新月狼灵(36级，**游戏夜晚** + 月之牙) → 银月狼王
- 支持**双人骑乘**

## 五、对辅助器/自动化的启示

1. **"连续捕捉触发奇遇"是一个可自动化的循环**：`找野生精灵 → 战斗/投球 → 计数 → 触发后检测天光变夜 → 判色 → 白月抓、紫月跳`
2. **天光变夜可作为事件触发的视觉判据**（全屏色调/亮度突变），比 OCR 文字更早、更快
3. **眠枭庇护所的「传送」按钮**是合法的定点移动手段——比在地图上找传送点图标更可靠（地图图标定位一直是难点）
4. **出现时段字段（全天/白天/夜晚）**说明游戏内有昼夜系统，自动化排程需考虑时段
5. `tools/teleport.py` 的分辨率适配仍是待修项（MIX 3 上开地图点击错位，实测点到截图按钮）
