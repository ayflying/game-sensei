## 一、两条线、两套机制（关键差异）

| | 花草（植物） | 矿物 |
|---|---|---|
| 典型产地 | 草原、花海、树下、石缝、草丛 | 山地岩层、深山洞穴、山脚碎石坡 |
| 采集动作 | **靠近花朵 → 点「采集」** | **必须用宠物**：长按丢球 → 瞄准矿石到出现「手」标记 → 释放宠物 |
| 工具 | 无 | 镐头（铁/银/金/防爆）；挖水晶约 20 秒 |
| 刷新 | 花朵类约 2 天 | 矿石类约 3 天，每日限采 3 次 |
| 人物自己走过去 | 可以（点采集即可） | **完全无效**，必须靠宠物 |

> ⚠️ 本文件此前一度按「骑乘精灵会自动采集」理解，与「靠近点采集」冲突 —— 以真机为准。

## 二、找采集点的手段

1. **元素视野（最有效）**：队伍携带 **果冻 / 海盔虫 / 蚊子** 之一，
   可**不切换坐骑**直接开启元素视野，看到采集点的发光标记。
   —— 视野消耗体力，路线熟练后可不带。
2. **「爱分享」特性**：越多越好、可叠加，直接提升产出（攻略称 6 只爱分享
   跑一轮约产出花 110 + 矿 40）。
3. **坐骑**：钩锁类（粉耳星兔，平地快、体力消耗低）或大跳类（梦想三三）。

## 五、与项目已有结论的关系

- 采集物**不在**图标库 24 条里（那些全是"点开弹提示"的导航类设施）⇒
  采集物需要**新的识别方式**（元素视野高亮 / 颜色特征 / VLM 探索）。
- 大世界**没有可交互目标时 OCR 只有导航文字**（`detect_state` 会判 `unknown`），
  靠近采集物后是否出现文字提示，是判据设计的关键未知项。
