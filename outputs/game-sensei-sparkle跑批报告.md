## 三、胜负判据（避免自欺的关键）

判胜步 = 第 12 步「胜负判定（只等不动）」，`ACTION WAIT` + **`strict: true`**，
判据 = 结算页顶部大字（`region=[0.10,0.08,0.90,0.175]`，`color=[255,235,255]`，`tol=18`，
`min_ratio=0.06`）。离线复算分离度：

| 画面 | 大字占比 | 判据结论 |
|---|---|---|
| WINNER 结算页 | 11.1 ~ 15.2% | 命中（≥6%）✓ |
| LOSE 结算页 | 1.9 ~ 2.2% | 不命中 ✓ |
| 其他界面 | ≤ 5.1% | 不命中 ✓ |
| 广告帧（最坏情形） | 可达 18.2% | ⚠️ 需门禁（已由「等结算页出现」前置步挡住） |

⇒ 败局 `strict` 失败 → 退出码 1；胜局通过 → 退出码 0。**胜率可直接从退出码统计**。

> ⚠️ 反面教材：不可用「结算页紫色 Exit 按钮」判胜负——WINNER / LOSE 两态占比都是 93.7%，
> 会让两侧结论反过来，**唯一能走完的路径恰好是败局**。

## 四、结论

| 判据 | 结果 | 证据 |
|---|---|---|
| ① 端到端含终态校验跑通 ≥1 次 | ✅ | run29 / 35 / 39 |
| ② 连续 ≥10 次 WINNER ≥80% | ❌ **30%**（两轮 40% / 20%） | 14 局 LOSE 退出码均为 1 |
| ③ 抓帧失败必须重试 | ✅ | batch 起点重试；plan 内 P0 安全检查 |
| ④ README 补章节 | ✅ | README §12.6 / §12.7 / §12.8 |
| ⑤ 判据能捕获败局 | ✅ | 14 局 LOSE 退出码 1 + 终态帧独立复核为 LOSE 页 |

**判据② 与游戏类型不匹配**：Sparkle 是换装评分对战，「赢」由**装扮内容**决定
（要选到与主题匹配的造型），属**决策·策略层**；`-plan` 属**执行层**。
14 局败局的装备步与提交步**全部执行、动作失败 0 次**，仍输 ⇒ 根因在决策层。
两轮胜率 40% / 20% 的剧烈波动**本身就是证据**：胜负由「随机出的主题 vs 固定点的服装卡
是否匹配」决定，执行层无法左右。

⇒ **收尾口径**：以 ①③④⑤ 收尾，②改判为「**胜负判定正确 ∧ 败局可捕获 ∧ 终态正确**」，
合并 30% 胜率作**基线**如实记录。要「稳定打赢」须在**决策层**另做（读 `Level / 主题 /
Style Tips` → 选卡），不在本线范围。**下一款 `-plan` 游戏优先选胜负由操作决定的类型**。
