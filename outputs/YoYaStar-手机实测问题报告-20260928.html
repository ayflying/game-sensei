严重

公告弹窗反复自动弹出，拦截主界面入口，NEW 无法进入

发生时间：2026-09-28 16:22 – 16:23（连续复现 2 次）

现象：关闭 Notice 公告弹窗后主界面恢复正常、按钮全部可见（证据 A）；随后点击主界面右侧的 NEW 按钮，Notice 公告弹窗**立即重新弹出**并遮挡整个界面，NEW 页面没有被打开（证据 B）。相同操作连续执行两次，结果一致。

影响：NEW 入口在弹窗反复弹出的情况下实际无法进入，用户每次点击都会被公告打断。

证据：A 关闭弹窗后的干净主界面；B 点击 NEW 后弹窗重现。

证据：左图为清晰可见的一次；右图为另一次复现（面板内容不同、串字现象相同）。

三、测试环境与配置问题（非游戏缺陷）

1. 无线 ADB 反复掉线（测试期间中断 4 次以上）
实测报错为 adb server version (40) doesn't match this client (41); killing...——本机同时存在不同版本的 adb 客户端，共用 5037 端口时互相终止服务，导致设备连接频繁断开。统一改用 Android SDK 版 adb 后连接稳定。此为测试环境问题，非游戏缺陷。
2. 设备分辨率与项目档案标定不一致
本机实测 720 × 1600（density 300）；而项目 YoYa Star 档案此前按 1080 × 2340 标定。因此本次所有点击坐标均按当前设备重新换算，历史坐标不可直接复用。
3. 图片判读渠道
首个接口密钥鉴权返回 401（Invalid API key）；更换密钥后鉴权通过，但所指定模型的多数名称在该网关上不存在（返回 HTTP 503），最终改用网关上实际存在的视觉模型完成判读。此项属配置问题，非游戏缺陷。
